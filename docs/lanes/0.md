# Lane 0: ESP-IDF 6.1 rebaseline (LOCAL ONLY)

Runs on the maintainer's machine with the physical board. Not a cloud
lane. Run before lanes that generate new evidence.

Scope and checklist: [`../roadmap.md`](../roadmap.md), "Toolchain
currency". In short: rebuild fixture ELFs under v6.1 and re-pin;
rerun receipt cohorts and confirm silicon-architectural numbers are
bit-identical; re-measure IDF-code-path numbers (interrupt entry/resume,
boot time); one flag day, no toolchain mixing; keep the 6.0.2-versus-6.1
delta as a toolchain-sensitivity receipt.

Working trees: `tinydraw` (calibration projects, fixtures) and this
repository (baseline pins in `experiments/esp32s3-flexe-wasm/*.json`,
`packs/esp32-s3-touch-amoled-18/timing/`).

Exit: all pins updated, cohorts rerun on two boots, STATUS.md notes the
flag day, delta receipt committed.
